# How should "teacher-checked" skills count?

Curriculum v3.2 has **20 skills, all in worlds 6–9** (NQ-05 and up), that the game can't check and that the curriculum says need a "teacher / independent reviewer". Examples:
- read an unseen excerpt
- accompany a singer
- run a mock recital
- improvise a solo
- record a meaningful performance

The game can't tell who is holding the tablet, so a "teacher" button would only be a label. I need to know how these count toward finishing a stop and toward Journey Readiness.

**A. Any grown-up can confirm (recommended).**
- Same as today's `caregiver` checks: a grown-up says "yes, she did it" behind the grown-up hold, on two different days, and the skill is secure.
- The grown-up can mark the yes as "teacher" or "grown-up". That only changes the label saved with it, so you can see later which came from a teacher.
- This matches J2/J4 (readiness already takes caregiver or teacher), and a learner with no teacher is never stuck.

**B. Teacher only.**
- The yes must be marked "teacher". Stricter on paper, but the game can't verify it.
- A learner with no teacher can't finish these stops.

**C. Bonus, never blocking.**
- These skills never hold back a stop or readiness. They show as "ask your teacher" extras and are recorded when someone confirms them.
- This is the gentlest option for self-taught learners, but worlds 6–9 then have no required performance check for these skills.

Nothing is built for this yet. I'll build whichever you pick when the curriculum swap happens.
