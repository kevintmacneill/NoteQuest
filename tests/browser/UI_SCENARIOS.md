# WP-1.1 initial scenario tranche

This is a draft, not the completed crawler. It starts with Claude's experimental evidence and replaces direct route jumping with real clicks for fresh creation, actual returning launch, Continue Adventure and browser Back from Music Reference. It uses only loopback and isolated browser contexts with fictional learners. It records five viewports, state snapshots, legacy routes, error messages, screenshots and a visible-control inventory; unexplored controls are explicitly reported. It captures a candidate baseline rather than fabricating a known-failure baseline. After independent review of actual output, pin baseline observations by commit/scenario/viewport/route, add replay graph traversal, multi-learner/guardian/history scenarios and checked external exits, then remove informational CI mode and demonstrate a deliberately introduced route fails. Current draft is not acceptance evidence for M3 or all clicks. Existing browser suites remain unchanged.
