# WP-1.2 performance baseline

Run `python tests/browser/performance_baseline.py` with Playwright Chromium installed. The script serves the checkout over loopback, uses fresh contexts and disables caching. External requests are blocked. It captures five viewport orientations and records the checked-out commit, network conditions, visible Tap to Play time, categorized encoded transfer bytes through one second after readiness, page/request errors and screenshots. CI uploads the JSON and PNGs. The measurement is informational: no speed or byte threshold is enforced until calibrated on actual target hardware. The test does not seed, modify or contact real learner saves. A missing sample is a measurement error, not a passing performance result. The browser measurements are not hardware acceptance.
