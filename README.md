# Note Quest 🎹🚀

A piano note-reading game for young beginners, following the end of Alfred's Basic Piano Prep Course Level A (bass staff → treble staff → grand staff → Middle C position).

**Play:** https://kevintmacneill.github.io/NoteQuest/

- Note Planets: Name It, Find It, Play It, Meteor Shower (15-meteor and endless)
- Unicorn Rescue, Rhythm Rocket (beat counting + hold-along), Song Station
- Pet world: earn coins by practicing, feed and care for pets, clean habitats, decorate; pets grow baby → kid → adult
- Hot Spring with capybaras, Magic Meadow with a deluxe unicorn
- Expeditions: design an explorer, rescue Amazon rainforest animals (Animal Tracks note game → treasure chests → rescue → Field Journal or Rescue Sanctuary)
- Piano listening through the microphone (single notes) and a grown-up Mic test
- Grown-up view: progress per note, settings, bonus coins, move progress between copies

Everything is in one file, `index.html`. Progress saves in the browser on each device.
Printables: flashcards, worksheets and song sheets (PDFs in this repo).
